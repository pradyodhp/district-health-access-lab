# Processed data dictionary

Generated by `python3 scripts/build_data.py`. One CSV row is one **sex-specific district indicator in a survey wave**; it is never a population count.

| Column | Unit / meaning | Origin | Status |
| --- | --- | --- | --- |
| `state`, `district` | Name as in source CSV | NFHS community parse | OBSERVED identifier |
| `state_census_code`, `district_census_code` | Source-supplied 2011 identifiers; not verified current boundaries | NFHS community parse | OBSERVED identifier, provisional |
| `indicator_id`, `indicator_label` | Internal key and original verbatim source wording | code / NFHS parse | DERIVED key / OBSERVED text |
| `sex`, `age_group` | Adult female/male, age 15+ | NFHS fact-sheet indicator section; verify PDFs | OBSERVED metadata, provisional |
| `value_pct` | Percentage, 0-100; blank when unavailable | NFHS-5 column of parse | OBSERVED pending verification; NFHS-4 withheld |
| `value_status` | `OBSERVED_UNVERIFIED` or `UNAVAILABLE` | extraction rules | DERIVED quality label |
| `wave`, `survey_vintage` | NFHS-5 = 2019-21, NFHS-4 survey = 2015-16 | survey publications; not retrieval date | OBSERVED period metadata |
| `source_url`, `source_sha256`, `retrieved_on` | Row lineage to immutable raw snapshot | extraction manifest | PROVENANCE |
| `caveat` | Interpretation, including NFHS-4 zero handling | extraction rules | DERIVED caveat |

`ASSUMED` values are **not** present in this table. Future assumptions need their own keyed provenance record, value or distribution, author rationale, validity window and scenario id. Never relabel a model assumption as an observed survey result.
